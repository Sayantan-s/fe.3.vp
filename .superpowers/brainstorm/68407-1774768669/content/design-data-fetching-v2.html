Design — Section 3 (revised): Data Fetching & Loading States

Single hook, Promise.allSettled, concurrent fetch, distribute to providers

Fetching Strategy (revised)

useStudioData hook — single concurrent fetch
// hooks/use-studio-data.ts
// Single hook, single useEffect, single tick

function useStudioData(videoId: string) {
const [state, setState] = useState({ ... });

useEffect(() => {
const controller = new AbortController();

const results = await Promise.allSettled([
fetch(`/api/video/${videoId}`, { signal }),
fetch(`/api/video/${videoId}/transcript`, { signal }),
]);

// Destructure independently — one failure doesn't block the other
const [videoResult, transcriptResult] = results;

const videoData = videoResult.status === "fulfilled"
? await videoResult.value.json()
: null;

const transcriptData = transcriptResult.status === "fulfilled"
? await transcriptResult.value.json()
: null;

// Single setState with both results
setState({ videoData, transcriptData, ... });

return () => controller.abort();
}, [videoId]);

return { videoData, transcriptData, videoError, transcriptError, isLoading };
}

How It Connects to Providers

StudioProvider uses the hook, passes results down
// StudioProvider.tsx

function StudioProvider({ videoId, children }) {
const { videoData, transcriptData, ... } = useStudioData(videoId);

return (
<VideoDataProvider initialData={videoData} ...>
<TranscriptProvider initialData={transcriptData} ...>
{children}
</TranscriptProvider>
</VideoDataProvider>
);
}

// useStudioData fires BOTH fetches in one Promise.allSettled
// Each provider receives its slice of data as initialData
// Providers own local state + actions from that point on

Why This Reduces Latency

Before vs After
Before: Two independent useEffects
VideoDataProvider
fetch /api/video
TranscriptProvider
fetch /api/transcript
Two effects → two microtask queues → potential scheduling gap
After: Single useEffect + Promise.allSettled
useStudioData
video
transcript
One effect → both fire in same tick → allSettled waits for both → single state update

AbortController

Cleanup aborts both in-flight requests if videoId changes or the component unmounts. Single controller for both fetches.

Loading / Error / Skeleton layers remain the same

Route-level loading.tsx per slot, data-level isLoading from context, Suspense around lazy Player — unchanged from the previous section.
